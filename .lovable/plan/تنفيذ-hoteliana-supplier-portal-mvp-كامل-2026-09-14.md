# تنفيذ Hoteliana Supplier Portal — MVP كامل

## الهدف
تحويل جميع شاشات صفحة **06 — MVP Final UI** إلى بوابة تفاعلية مترابطة، مع مطابقة نظام التصميم في صفحة **05 — Design System**: ألوان Hoteliana، خطوط Readex Pro وInter، المسافات، الحواف، الحالات، والأزرار.

تعمل البوابة بالكامل بالعربية والإنجليزية، مع زر لتبديل اللغة وتغيير اتجاه الواجهة تلقائيًا بين RTL وLTR.

## نطاق التنفيذ

### 1. تأسيس نظام التصميم
- تعريف الألوان الدلالية: الخلفيات، النصوص، الحدود، الأخضر الداكن، الليموني، وحالات النجاح والتحذير والخطأ والمعلومات.
- تحميل Readex Pro للواجهة بالإنجليزية، وCairo للواجهة العربية، وInter للبيانات والجداول.
- إعداد النصوص باللغتين العربية والإنجليزية مع الحفاظ على نفس التسلسل البصري والمصطلحات في جميع الحالات.
- إنشاء عناصر مشتركة مطابقة لـFigma: الأزرار، الحقول، الشارات، البطاقات، التبويبات، النوافذ، الأدراج، شريط التغييرات، وشريط التنقل.
- دعم RTL للعربية وLTR للإنجليزية، والاتجاه المتجاوب للشاشات المكتبية والمحمولة مع الحفاظ على كثافة واجهة سطح المكتب.

### 2. الوصول والحساب
- تفعيل الحساب.
- تسجيل الدخول وحالة البيانات الخاطئة.
- رمز التحقق بخطوتين وحالة الرمز المرفوض.
- استعادة كلمة المرور وإنشاء كلمة جديدة وحالات عدم التطابق.
- شاشة البدء الأولى بعد تفعيل الحساب.

### 3. الاتفاقية وبيانات الشركة
- عرض الاتفاقية وبيانات الشركة والعقد للقراءة فقط.
- طلب تعديل بيانات الشركة: اختيار الحقول، إدخال البدائل، إرفاق المستندات، المراجعة، والتأكيد.
- قائمة طلبات التعديل وتفاصيل الحالات الموجودة في التصميم.

### 4. مكتبة الفنادق والطلبات
- استعراض مكتبة الفنادق، البحث والتصفية، الاختيار، وطلب الوصول.
- حالات الفندق: متاح، محدد، مطلوب، وغير متاح.
- صفحات الطلبات وتفاصيل الطلب وحالات القبول/الانتظار/الرفض حسب Figma.
- صفحة فنادقي والحالات الفارغة والمعبأة.

### 5. عقود الأسعار وإعداد الفندق
- إنشاء وإدارة عقد السعر وفق خطوات Figma.
- الغرف، خطط الوجبات، المواسم، الأسعار، القيود والمخزون.
- حالات المسودة، التحقق، التعارضات، والمراجعة النهائية.

### 6. تقويم الأسعار والمخزون
- شبكة التقويم الشهرية وحالات الخلايا المعرفة في نظام التصميم.
- التحرير السريع، تحديد النطاق، إيقاف البيع، والمخزون المنخفض/الصفري.
- شريط التغييرات المعلقة، التعارضات، الحفظ والتأكيد.

### 7. الحجوزات والمالية والفريق
- شاشات الحجوزات والقوائم والتفاصيل والحالات المتاحة في ملف الـMVP.
- شاشات التسويات/المالية والجداول والملخصات.
- شاشات الفريق والصلاحيات الموجودة في التصميم.
- التنقل العلوي بحالتيه المطوية والموسعة وربط كل الأقسام.

## التفاعل والبيانات
- تنفيذ الانتقالات والأزرار والنماذج والفلاتر والنوافذ كواجهة تجريبية كاملة.
- توفير تبديل واضح للغة، مع بقاء المستخدم في الشاشة والحالة نفسها عند التبديل.
- استخدام بيانات العرض نفسها الظاهرة في Figma، مع الاحتفاظ بالحالة داخل الجلسة دون إضافة خدمة تخزين خارجية.
- محاكاة الرفع والمعاينة والتنزيل بصريًا دون إرسال ملفات إلى خادم.

## التحقق
- مراجعة كل شاشة مقابل لقطة Figma وقيمها الدقيقة.
- اختبار المسارات والتفاعلات الأساسية من الدخول حتى إدارة الفندق.
- فحص العرض المكتبي والمحمول، ومنع التداخل أو قص النصوص.
- اختبار كل شاشة باللغتين وفي اتجاهي RTL وLTR.
- التأكد من اكتمال عناوين ووصف كل صفحة وعدم وجود أخطاء تشغيل.

## تفاصيل تقنية
- React 19 + TanStack Start + TypeScript + Tailwind CSS v4.
- تقسيم الشاشات إلى مسارات فعلية وعناصر واجهة قابلة لإعادة الاستخدام.
- استخدام رموز دلالية فقط للألوان والظلال والخطوط داخل نظام التصميم.
- لا يتضمن هذا النطاق تسجيل دخول حقيقيًا أو قاعدة بيانات؛ جميع التدفقات ستكون Prototype تفاعليًا مطابقًا للتصميم.
