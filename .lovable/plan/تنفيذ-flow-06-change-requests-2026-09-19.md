# تنفيذ Flow 06 — Change requests

## النتيجة
إنشاء مساحة مستقلة لطلبات تغيير الحجوزات داخل قسم Bookings، مطابقة لشاشات Figma الـ27، ومتصلة ببيانات الحجوزات الحالية وحالاتها. ستعمل بالإنجليزية والعربية مع RTL وخط Cairo، وعلى سطح المكتب والهاتف.

## الصفحات والمسارات
- إضافة صفحة قائمة طلبات التغيير وربطها من قائمة الحجوزات: `/bookings/change-requests`.
- إضافة صفحة تفاصيل موحّدة لكل طلب: `/bookings/change-requests/$requestId`، ويتغير محتواها حسب نوع الطلب وحالته.
- إبقاء صفحة Bookings الحالية كما هي، مع روابط صحيحة بين الحجز الأصلي وطلب التغيير والعودة للقائمة.

## قائمة طلبات التغيير
- مطابقة الرأس، عداد `3 waiting on you`، بطاقات الطلبات العاجلة الثلاث، وفلاتر النوع: All، Cancellations، Amendments، Waiting on the agent، Handled.
- إدخال بيانات Figma نفسها للطلبات: HTL-88191، HTL-88198، HTL-88166، HTL-88159، HTL-88176، HTL-88144، HTL-88131، HTL-88154.
- تنفيذ البحث، اختيار الفندق والنوع والفترة، ترتيب النتائج، وعدّادات النتائج.
- تنفيذ حالات القائمة المنفصلة للفلاتر الأربعة، جدول سطح المكتب وبطاقات الهاتف، وزر Load more.
- تنفيذ نافذة الفلاتر المتقدمة، نافذة البحث ونتائجه، نافذة التصدير وخيارات CSV/Excel، وقائمة إجراءات كل صف.

## تدفق الإلغاء
- طلب إلغاء الحجز بالكامل مع السياسة المثبتة، الخط الزمني، الحد الأقصى للرسوم، وتأثير إعادة الغرف.
- خيارات القرار: تحصيل كامل المبلغ، تحصيل مبلغ أقل مع حساب المكتوب-off، أو الإعفاء الكامل مع ملاحظة.
- تأكيد كل اختيار في نافذته المطابقة، ثم تحديث حالة الحجز والطلب والمبلغ والحالة المالية وسجل الأحداث.
- دعم الإلغاء الجزئي لـ2 من 5 غرف، وتقصير الإقامة بإزالة ليلتين، مع الحسابات وتأثير المخزون المنفصل لكل حالة.
- صفحة النتيجة النهائية: Cancelled، Charge pending، الغرف المعادة، المبلغ، النسخ، والسجل الزمني.

## تدفق التعديل
- تعديل تجاري بسعر محسوب مسبقًا: عرض التغيير، فحوصات المحرك الثمانية، السعر، ثم اعتماد السعر أو اقتراح سعر مختلف أو الرفض.
- نافذة اقتراح سعر 700 SAR، وحالة `Waiting on the agent` دون حجز غرفة، ثم تحديث الحجز عند القبول فقط.
- حالة الاعتماد النهائية بإنشاء Booking v2، تحديث الليالي والقيمة والمخزون، مع إبقاء v1 محفوظًا.
- حالة الرفض النهائية مع السبب وبقاء الحجز والمخزون والسعر دون تغيير.
- طلب عرض سعر بلا سعر متفق عليه، مع إرسال السعر للوكيل بدل تطبيقه فورًا.
- تعديل غير تجاري لاسم الضيف: اعتماد/رفض دون أي حركة مالية أو تغيير مخزون، مع إنشاء النسخة الجديدة عند الاعتماد.

## الربط والحالة المشتركة
- إضافة نموذج بيانات مخصص لطلبات التغيير، أنواعها، حالاتها، السياسة، المبالغ، النسخ، والفترات الزمنية.
- توسيع حالة البوابة بإجراءات الإلغاء، التسعير، الإعفاء، الاعتماد، الرفض، العرض، والسحب؛ كل إجراء يحدّث القائمة والتفاصيل والحجز المرتبط في الجلسة نفسها.
- ربط Report an issue بالحالة الموجودة حاليًا في الحجوزات دون تغيير حالة الحجز تلقائيًا.
- التصدير ينشئ ملفًا فعليًا بالصفوف والأعمدة المختارة.

## المطابقة والاختبار
- استخدام نفس نظام الألوان والمسافات والخطوط والمكونات الحالي، مع قيم Figma الدقيقة للرؤوس والبطاقات والجداول والنوافذ والحالات.
- نصوص كاملة EN/AR، وCairo للعربية، واتجاه RTL صحيح للأزرار والأسهم والجداول.
- اختبار جميع الانتقالات والقرارات والفلاتر والبحث والتصدير على 1280px و393px، مع منع التمرير الجانبي وأخطاء الواجهة.
- التحقق من عناوين ووصف المشاركة لكل صفحة جديدة، ثم التأكد من نجاح البناء.
